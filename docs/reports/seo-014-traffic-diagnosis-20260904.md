# AsiaPower 流量诊断与修复记录

观察日期：2026-09-04 UTC。更新：2026-09-05 已完成生产发布和复查，流量改善尚待后续数据验证。详见 [上线与跟进记录](seo-014-traffic-20260904/deployment-20260905.md)。下文保留诊断时的证据与阶段状态。

## 结论

网站的自然获客规模确实很小，而且最近一周 GA4 用户和会话都在下降。当前不是全站不可访问或大面积禁止收录的问题。最有证据支持的改进顺序是：修复库存渲染的抓取障碍，清理统计噪声，改进已经有搜索展示的商品入口，然后建立稳定的内容和分发渠道。

不能仅凭本轮数据证明某一项技术问题造成了全部流量下降。本站统计、GA4、GSC 各有口径，不可相加或混用。

## 2. 已确认问题与本轮处理

### P1：robots.txt 阻止用于渲染库存的公开接口

生产规则 `Disallow: /api/` 会阻止 Googlebot 获取 `/api/half-cuts/public`。首页脚本依赖此接口；目录的所谓服务端预渲染主要注入JSON-LD，并没有把完整商品列表写入可见HTML。因此，接口可抓取性确实与页面渲染有关。

本地修复：仅放行公开目录及单件查询的准确路径和查询参数形式；管理、上传、数据目录仍保留禁止抓取规则。具名AI爬虫与通配爬虫合并到同一规则组，避免具名组意外绕过原本的目录排除。

这不改变API身份验证、数据权限或公开字段。已核查这两个接口使用现有公开库存序列化逻辑。robots.txt 本身也不是访问控制。

验证：独立 robots-parser 对 Googlebot、bingbot、OAI-SearchBot、GPTBot、ClaudeBot、PerplexityBot 共66项访问判断全部通过。

限制：尚未上线，也未通过 GSC 实时测试证明软404已恢复；不能宣称该修复一定带来排名提升。[Google JavaScript SEO 文档](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics)说明，受robots阻止的资源不会被抓取，服务端渲染有助于用户和爬虫获取内容。

### P1：扫描请求污染PV，周报错误称其为“真实”流量

本地新增狭窄过滤器，排除WordPress REST探测、常见WordPress/版本库/环境文件路径，以及文件参数中的目录穿越。正常库存搜索、商品slug、UTM和广告参数保留。

同步修正周报措辞：排除7个已知内测IP后，仍不能标为“真实买家访问”。保留原始历史数据；不按地区大范围删除用户，不追溯改写计数。

验证：3项回归测试通过，涵盖已观测攻击地址、正常商品/营销链接及真实统计入口；语法检查和周报文案检查通过。这个修复提高判断质量，本身不会创造流量。

### P1：G4KD 商品内容暴露内部运营说明，并混淆适配关系

现网页面出现 repository signals、内部文件路径、跟进优先级建议等文字；原适配表把同一组年份/变速箱复制到不同车型行。搜索访客需要的是能买到什么、是否匹配、如何确认，而不是内部工作流。原始页面不能据此认定所有车型年份都适配。

本轮已完成G4KD内容预览：移除内部运营措辞；连接3条当前公开库存示例；明确半切车价格不是发动机单价；把车型与年份作为具体供体信息，不作为普遍兼容表；保留核实条件，不编造功率、价格、保修或供货承诺。

本轮公开接口读到5条G4KD记录，其中1条是整车，预览选取3条半切车例子。预览不提交询价，不写入生产模板，也不批量覆盖其他发动机页。

[打开本地预览](http://127.0.0.1:8764/docs/previews/seo-014-traffic-20260904/g4kd-preview.html)。使用现有站点样式，桌面和390px手机宽度均已目视检查，手机文档宽375px，没有横向溢出。

## 3. 网站现状诊断

- **收录并非全面失败。** GSC索引报告更新于2026-08-28：771页已收录，543页未收录。其中379页是有正确规范标记的备用页，109页是重定向，合计488页，通常不应强求收录。另有26个404、5个软404、2个重定向错误、1个noindex、1个未指定规范重复页、11个已抓取未收录、9个Google选择不同规范页；应按URL判断，不能全部统一重定向到首页。
- **真实软404需跟进。** 样例包括 `/trucks/`、带BMW/BYD过滤的二手车目录，以及2AZ-FE/HC250513搜索页。先上线抓取修复，再检查Google渲染结果；必要时对目录补充服务端可见库存，对无结果筛选页制定独立索引策略。本轮未执行未经验证的“验证修正”。
- **可用性基础正常。** 现网站点地图781个URL；其中192个不带参数的页面全部HTTP 200。没有全面检查其余589个参数商品URL，也不能把200当成已收录。首页、robots和sitemap均可访问；本轮直接读取config.js和sw.js的缓存均是60秒，历史4小时缓存问题不能继续当作当前故障。
- **手机首屏偏重理念表达。** 390px实测首页无横向溢出，但多行品牌宣言占了较多空间，库存位于下方。建议保留循环经济品牌定位，同时让买家更快看到品类、可用库存与采购路径；先做预览，不直接重做生产首页。
- **英文内容仍有明显中文残留。** 首页英文状态可见“宝马X1(进口)”“柯斯达”等名称。需要在准确车型映射基础上修正显示，不能凭猜测改库存原始车型。本轮保留已有未提交的车型标准化工作。
- **异常低价值得核实。** 首页卡车驾驶室出现10美元和50美元价格。未证明是录入错误，不能直接改价；应由供应商确认完整单位、币种与报价范围。
- **渠道过于单薄。** 本周自然搜索8次、付费搜索6次、引荐3次会话。缺少持续、可归因的商品内容分发；仅增加页面数量不足以解决。Direct中未标记来源占比未知。
- **结构化数据仍有待查项。** GSC概览显示产品摘要/商家信息各2个无效页，问与答1个、视频1个无效项。本轮未逐项确认错误字段，不把这些项写成已修复或下降主因。

## 4. 提高有效访问量的执行顺序

### 第一周：把已有入口修好

1. 批准后先发布抓取和统计修复，验证线上robots、库存接口与正常搜索计数；回滚以本次Release Manager备份为准。
2. 审阅G4KD预览后，把相同原则应用到生产页及生成器，避免下次生成把内部说明写回来。先做这一个有25次展示、但0点击的页面，核查真实库存和内链，再扩到其他页。
3. 对BYD472QC/BYD472ZQB已经获得展示的整车详情核查车型、动力类型、标题与旧slug跳转。它们是整车需求入口，不能为了发动机关键词改成拆车发动机广告。
4. 在GSC实时检查 `/trucks/` 及重点目录，修复仍存在的软404后再请求验证。192个正常页面不需要全站重做。

### 第2—4周：围绕真实采购问题增加入口

1. 每周完成2篇经过事实核查的采购内容，先围绕有库存的发动机代码、发动机与半切车采购范围、出口报价比较；链接到具体库存，避免批量低信息模板页。
2. 从现有真实库存媒体制作每周3条简短商品介绍，内容包含型号、库存号、条件及对应详情链接；视频/图片权利确认后再发布。客户外发与社交发布需要明确授权，本轮未自动发布。
3. 对已获准投放的自有渠道使用一致UTM。统计“渠道→商品页→有效询盘”，不要用访问次数或WhatsApp按钮点击替代业务结果。
4. 付费推广先核实转化事件与预算，再进行小规模试验；本轮不修改广告账户、出价或预算。

建议30天试验目标（不是增长预测）：GSC滚动28天点击26→50；GA4每周自然搜索会话8→15；单独记录可识别采购需求的有效询盘，待第一周人工核验建立基线后再设询盘目标。按相同完整时间窗口比较，观察来源、目标市场、落地页及有效询盘，不能承诺订单数量。
