# 发动机型号索引与单篇车型汇总规则

日期：2026-09-10。适用于本轮全部 52 个候选研究单元及后续新增型号。

## 一种完整型号代码，一篇主文章

主索引为发动机型号代码，例如 BYD472QC、SQRF4J16。每台机器独有的发动机序列号／出厂流水号只记录在具体商品中，不拿来建立博客分类。

同一代码用于多个品牌、车型、年款，全部汇总在这篇文章里。品牌或车型导航链接到文章对应章节，不重复建立“同代码＋不同车型”的同义选购文章。已有捐赠车商品详情和真实交付案例仍可独立存在，它们不是重复型号指南。

不同完整后缀原则上分开；只有原厂资料证实为同一代码的不同写法，才作为别名处理。不可自动删除后缀，也不能将 GW4G15 与 GW4G15B、BYD472QC 与 BYD472ZQB 合并。

## 每篇文章固定顺序

1. 型号简介和参数；参数与具体版本绑定。
2. **搭载品牌、车型、年款及版本汇总表**，放在前部，供读者快速查找。
3. 不同车型／年份的附件、控制系统、安装接口与标定差异。
4. 常见购买疑问、有可靠依据的故障信息及检验要点。
5. 裸机／长机／带附件总成／混动动力组件的供货范围。
6. 本型号真实商品和询价入口；与整车购买入口明确区分。

## 车型汇总表字段

| 字段 | 内容要求 |
|---|---|
| 品牌 | 可以跨品牌，同代码只占一篇主文章 |
| 车型／车系 | 使用准确全名，区分 EV、DM-i 等动力版本 |
| 年款 | 不把手册日期、上市日期或上牌年份直接当年款 |
| 生产适用区间 | 有依据才写起止年月，不能把两个孤立年款拼成连续范围 |
| 具体款型／配置 | 明确动力、驱动形式及必要的配置差异 |
| 整车型号／认证代码 | 优先保留原厂表中可核验的精确标识 |
| 销售市场 | 中国、其他市场分别注明；同名车不保证动力相同 |
| 发动机版本及关键差异 | 功率标定、控制系统、附件、变速箱连接等按证据填写 |
| 依据 | 原厂手册／零件目录／认证文件及适用版本 |

前台表格可分列或在同一单元格展开以适应手机，但不能省略影响适配判断的差异。

## 证据与完整性

目标是持续补齐所有已核实的搭载车型，而不是只写一款示例。未找到证据的年份和配置留在编辑待查清单，不猜测、不写成“全系通用”。对外明确“已核实的车型应用”，在未做完系统核验前不能称“全球全部车型”。

**搭载关系表不等于总成互换表。** 同代码跨车型仍可能存在外围附件、控制、接口及标定差异；需要单独说明是否已核实可直接替换。

## 知识由研究工作自行补齐

每篇正文的识别、故障判断、验货及安装知识由研究工作主动查找原厂和专业资料，并检查适用范围、反例和证据局限后写入。执行样例见[知识核验记录](knowledge-verification.md)。不把只列 FAQ 问题视为知识已经写完。
