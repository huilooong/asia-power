# AsiaPower 供应商媒体管理 V1 · 交互预览

## 目的

验证供应商对自己库存进行照片新增、移除、排序、封面设置、视频替换、关键参数编辑和客户侧实时预览的交互结构。

## 安全边界

- 读取 `https://asia-power.com/api/half-cuts/public` 的真实公开库存作为样例。
- 本地预览服务器只允许 `GET` / `HEAD`，拒绝所有写入方法。
- 添加的照片与视频只保存在当前浏览器标签页的内存中。
- “保存草稿”和“提交审核”会被预览弹窗拦截。
- 不改生产页面、URL、SEO、库存数据、询价逻辑或账户权限。

## 启动

```bash
node docs/previews/supplier-media-management-v1/server.mjs
```

打开：`http://127.0.0.1:8791/`

移动端验收框：`http://127.0.0.1:8791/docs/previews/supplier-media-management-v1/mobile-test.html`

## 已覆盖交互

- 真实库存载入与安全后备态
- 视频优先封面、首张照片作为静态后备封面
- 照片添加、移除、恢复、前后移动、拖动排序、设为封面
- 私有证据归档说明与恢复入口
- 品牌大写、型号、年份、里程、价格、库存状态编辑
- 目录卡片 / 移动端 / 详情页三种客户侧预览
- 桌面与移动响应式布局

## 不属于本预览

- 真实鉴权、对象存储上传、服务端校验
- 版本表、审核队列、审计日志与私有媒体权限
- 生产代码与部署
