www 会跳成 web：不要再改地址栏

这是 Facebook 自己的跳转，改回 www 还会被甩回来，会打转。

真正要改的只有发给 Google 的这一行：

https://web.facebook.com/oauth2/redirect/ → https://www.facebook.com/oauth2/redirect/

必须用普通 Chrome（不要无痕），并装下面插件。无痕里插件默认不工作。

装插件（一次，以后 Agent 也靠同一逻辑）

  1. 关掉所有无痕窗口
  2. 地址栏打开 chrome://extensions
  3. 右上角打开「开发者模式」
  4. 「加载已解压的扩展程序」
  5. 选文件夹 integrations/social_browser/chrome-facebook-www-guard
  6. 点插件「详情」，打开「在无痕模式下启用」（可选）
  7. 打开 https://web.facebook.com/（留在 web 即可）
  8. 再点「使用 Google 验证」

备用：手机版网页（有时不走这条 Google 回跳）

打开 https://mbasic.facebook.com/ 用邮箱+密码登录。
